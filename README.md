# 2D Війна на карті

Стратегія в реальному часі, одна гра в трьох реалізаціях:

| Папка | Мова / рушій | Запуск |
|---|---|---|
| `lua/` | Lua + LÖVE 11.x | `love lua` або GitHub Actions → `war2d.love` |
| `cpp/` | C++17 + raylib 5 | `cmake -S cpp -B build && cmake --build build --config Release` |
| `typescript/` | TypeScript + canvas | `cd typescript && npm install && npm start` → http://localhost:8080 |

## Правила
Ви — **сині** (ліворуч), ШІ — **червоні** (праворуч). Знищте штаб ворога (2500 HP). Гроші капають +14/с.
На карті є суша й море: танки ходять лише по суші, кораблі — лише по морю, літаки й шахеди летять над усім.

| Клавіша | Що | Ціна | Опис |
|---|---|---|---|
| 1 | Танк | 100 | суша, б'є землю й море |
| 2 | Літак | 250 | швидкий, б'є все, включно з повітрям |
| 3 | Корабель | 300 | море, великий радіус, б'є все |
| 4 | Шахеди ×3 | 90 | повільні дрони-камікадзе в точку кліку, їх можна збити |
| 5 | Ракета | 200 | з штабу в точку кліку, вибух 70 px |
| 6 | КАБ | 150 | скидає найближчий свій літак (не далі 400 px від цілі), вибух 55 px |
| 7 | Ядерка | 1500 | приліт за 3 с, радіус 230 px, зачіпає всіх (і своїх), перезарядка 45 с |

Для 4–7: натисніть клавішу, потім ЛКМ по карті. ПКМ або Esc — скасувати.
**P** — пауза, **R** — нова гра.

## GitHub
1. Створіть репозиторій і залийте вміст цієї папки (`git init && git add . && git commit -m init && git push`).
2. Вкладка **Actions** збере три версії автоматично; результат у **Artifacts**:
   - `war2d-lua-love` — файл `war2d.love` (запускається через LÖVE)
   - `war2d-cpp-Windows` — `war2d.exe` + папка `assets` (тримайте поруч)
   - `war2d-cpp-Linux`
   - `war2d-web` — сайт; щоб був онлайн: Settings → Pages → Source: **GitHub Actions**
3. Шрифт DejaVu Sans (вільна ліцензія) лежить у `lua/` та `cpp/assets/` для української мови.
